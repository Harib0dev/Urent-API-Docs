# Contributing

Спасибо за интерес к проекту. Цель репозитория - аккуратно документировать наблюдаемое поведение API без публикации приватных данных и без инструкций по обходу защитных механизмов.

## Что можно добавлять

- новые наблюдаемые эндпоинты;
- уточнения схем запросов и ответов;
- безопасные примеры с заменёнными идентификаторами;
- замечания о версии приложения, регионе, платформе и дате наблюдения;
- исправления OpenAPI-совместимости и отображения Swagger UI.

## Что нельзя добавлять

- JWT, refresh tokens, cookies, session IDs и другие секреты;
- реальные номера телефонов, email, ФИО, банковские данные и точные домашние координаты;
- инструкции по генерации или обходу `ur-request-data`;
- эксплуатационные сценарии, которые могут нарушать правила сервиса или мешать пользователям.

## Формат наблюдений

По возможности указывайте контекст рядом с эндпоинтом:

```yaml
x-observed:
  appVersion: "1.91.0"
  platform: ios
  region: RU
  confidence: medium
```

Если поле или ответ не подтверждены несколькими наблюдениями, лучше оставить схему шире через `additionalProperties: true`, чем представить догадку как точный контракт.

## Проверка

Перед pull request проверьте, что спецификация читается:

```bash
python3 - <<'PY'
import yaml
with open("openapi.yaml", "r", encoding="utf-8") as f:
    spec = yaml.safe_load(f)
print(spec["openapi"], len(spec["paths"]))
PY
```

GitHub Actions также запускает OpenAPI lint на pull request и push.
