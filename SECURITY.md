# Security Policy

## Sensitive data

Не публикуйте в issue, pull request или примерах:

- JWT, refresh tokens, cookies, request signatures;
- номера телефонов, email, ФИО, адреса и точные персональные координаты;
- данные банковских карт и платёжных операций;
- исходные логи, где могут быть приватные заголовки или идентификаторы.

Перед публикацией заменяйте значения на безопасные плейсхолдеры: `S.123`, `ORD12345`, `card_123`, `55.7558`, `37.6173`.

## Reporting

Если вы нашли проблему, которая может повлиять на пользователей или инфраструктуру сервиса, не публикуйте рабочий exploit и приватные данные в открытом репозитории. Описывайте только минимальный контекст, достаточный для понимания документационной ошибки.

## Scope

Этот репозиторий документирует наблюдаемое поведение API. Он не принимает материалы, связанные с обходом защит, несанкционированным доступом, вмешательством в поездки, платежи или аккаунты.
