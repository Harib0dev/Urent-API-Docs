# Urent API Docs

Неофициальная документация API сервиса аренды самокатов Юрент. Спецификация собрана по наблюдаемому поведению мобильного клиента, сетевому трафику и пользовательским логам.

> [!WARNING]
> Проект создан только для исследовательских и образовательных целей. Документация не предназначена для обхода ограничений сервиса, автоматизации поездок, вмешательства в работу инфраструктуры или публикации приватных данных.

## Документация

- Swagger UI: https://harib0dev.github.io/Urent-API-Docs/
- OpenAPI specification: [`openapi.yaml`](./openapi.yaml)

## Что внутри

- REST gateway: `https://app.urentbike.ru/gatewayclient/api`
- 110 HTTP/WebSocket операций из наблюдаемого трафика и статического анализа APK
- группы эндпоинтов для аренды, транспорта, зон, профиля, платежей, подписок и повербанков
- общие заголовки мобильного клиента: `ur-latitude`, `ur-longitude`, `ur-request-version`, `ur-request-data`, `environment-info`
- Bearer JWT authorization scheme
- отдельные наблюдения из Loon-сессий, без публикации сырых токенов и приватных данных
- отдельный [инвентарь endpoint'ов из Android APK](./docs/apk-static-analysis-1.90.2.md)
- базовые схемы запросов, ответов и ошибок

## Ограничения

API не является публичным контрактом. Эндпоинты, поля, статусы и требования к заголовкам могут отличаться по версии приложения, региону, платформе и состоянию аккаунта.

Алгоритм подписи `ur-request-data` намеренно не описывается. Если вы дополняете документацию, не добавляйте инструкции, которые помогают обходить клиентские или серверные проверки.

## Локальный просмотр

Любой статический сервер подойдёт:

```bash
python3 -m http.server 8080
```

Затем открыть:

```text
http://localhost:8080
```

## Как читать спецификацию

- `summary` описывает короткое назначение эндпоинта.
- `description` содержит наблюдения и ограничения, если они известны.
- `operationId` добавлен для генераторов SDK и импорта в инструменты вроде Postman/Insomnia.
- `additionalProperties: true` означает, что в реальных ответах могут встречаться дополнительные поля.
- Примеры не гарантируют полный ответ сервера, а фиксируют безопасную форму наблюдаемых данных.
